## 📝 Problem Statement

Given the **head **of a singly Linked List, return the **middle **node of the Linked List.

If the Linked List has an **even **number of nodes, return the **second **middle one.

### Example 1

<p>
**Input:** : head -> 3 -> 8 -> 7 -> 1 -> 3</p><p>
**Output:** (value at returned node): 7</p><p>
**Explanation:** : There are 5 nodes, so the middle node is the 3<sup>rd</sup> Node, with value 7.</p>

### Example 2

<p>
**Input:** : head -> 2 -> 9 -> 1 -> 4 -> 0 -> 4</p><p>
**Output:** (value at returned node): 4</p><p>
**Explanation:** : There are 6 nodes, thus both the 3<sup>rd</sup> and 4<sup>th</sup> nodes are middle. So the 2<sup>nd</sup> middle node (4<sup>th</sup> Node) is returned with value 4.</p>
