## 📝 Problem Statement

Given a binary tree root, find if it is **height-balanced** or not.

A tree is height-balanced if the difference between the heights of left and right subtrees is not more than one for all nodes of the tree.&nbsp;

**Input:** [3, 9, 20, null, null, 15, 7]
